FoodSaver AI

Problem Statement

Food waste is a major global issue. Many food items expire because people lose track of expiry dates and inventory. This leads to unnecessary waste and financial loss.

Solution

FoodSaver AI is a Python-based food management system that helps users track food items, monitor expiry dates, receive alerts, and generate waste-risk reports.

Features

- Add Food Items
- View Food Items
- Smart Expiry Recommendations
- Analytics Dashboard
- Search Food Items
- Waste Risk Report
- Expiry Alerts
- Generate Reports

Technologies Used

- Python
- CSV
- Datetime Module
- Git & GitHub

How to Run

1. Install Python
2. Clone the repository
3. Run:

python main.py
